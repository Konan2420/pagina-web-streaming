# Proyecto CMD Streaming

Este repositorio se desarrolla y publica de forma independiente desde VS Code. No se usa Lovable.

- Usa migraciones dentro de supabase/migrations para todo cambio de base de datos.
- Mantén secretos en .env.local; nunca expongas SUPABASE_SERVICE_ROLE_KEY al cliente.
- No reescribas historial remoto compartido sin autorización explícita.
